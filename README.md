# Synthkit: Your AI interaction guide and output finishing toolkit.

A curated collection of system prompts, structural templates, and transformation utilities designed to bridge the gap between **Generative AI outputs** and **production-ready documents**.

---

## 🛠 Project Overview
This repository serves as a personal "last-mile" delivery system for LLM interactions. It automates the process of taking raw Markdown generated by models like Gemini and Claude and converting it into polished formats for professional distribution.

### Core Workflow:
1.  **Prompt Selection:** Use high-context templates for consistent AI output.
2.  **AI Interaction:** Generate structured Markdown via web UI or API.
3.  **Transformation:** Run local scripts to convert Markdown into target formats (Email, PDF, etc.).
4.  **Distribution:** Clean HTML for email pasting, styled PDFs, or archival.

---

## 📂 Repository Structure

```text
├── prompts/              # Large-scale system & task templates
│   ├── email-drafting/   # Context-heavy prompts for professional comms
│   └── report-gen/       # Templates for structured analysis
├── tools/                # Transformation scripts (Python/Bash)
│   ├── md-to-email/      # CSS-inlined HTML for perfect pasting
│   └── md-to-pdf/        # Styled PDF generation (Pandoc/ReportLab)
├── assets/               # CSS stylesheets and PDF headers
└── examples/             # Sample inputs and transformed outputs

```

## 🚀 Getting Started

### Prerequisites

* **Python 3.10+**
* **Pandoc** (optional, for PDF workflows)
* **CommonMark** or **BeautifulSoup** (for HTML/Email cleanup)

### Installation

```bash
git clone [https://github.com/rappdw/](https://github.com/rappdw/)[REPO_NAME_PLACEHOLDER].git
cd [REPO_NAME_PLACEHOLDER]
pip install -r requirements.txt

```

---

## 📝 Usage

### Using Templates

Copy the contents of any file in `/prompts` into your LLM of choice. These are optimized for **Markdown-first** responses to ensure compatibility with the transformation tools.

### Running Transformations

To convert a generated markdown file for an email (copies styled HTML to clipboard):

```bash
python tools/md-to-email/convert.py input.md --clipboard

```
